# Security policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use GitHub's private vulnerability reporting feature for this repository. Include affected paths, impact, reproduction details, and any suggested mitigation. Do not include live credentials or customer data.

## Scope

Northstar is a learning application and simulated checkout system. It must not process real payments, personal data, or production credentials. The local Compose credentials are documentation-only defaults and are not suitable for a shared or internet-accessible environment.

Only the latest `main` branch is supported. Maintainers will acknowledge a complete private report when available, assess severity and affected versions, coordinate remediation, and publish an advisory when appropriate.
